## Approach

Two agent loops. The research loop edits one file in a target project, runs a fixed-budget experiment, keeps the change only if the metric improves and every negative control still passes, logs every run, and drafts findings here. The workflow loop proposes changes to the organisation's rules from review friction. Humans merge everything.
