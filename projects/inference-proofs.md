## Approach

An open benchmark for proof-of-inference systems. Every runnable prover gets the same request (a fixed 512-token prompt, a 512-token greedy reply), runs from a pinned public commit, and must pass six correctness and tamper-refusal gates before its cost is shown. Systems that cannot run yet are mapped with the reason. Methodology changes go through public RFCs.

## Status

Release candidate v0.1 at [inferenceproofs.ai](https://www.inferenceproofs.ai). Every number is at tier `reported`; none has been reproduced on hardware the maintainers do not control.
