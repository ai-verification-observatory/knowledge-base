# Workflows

How teams in the organisation work together. Each one is a proposal until the teams using it agree otherwise. Change one by pull request.

| Workflow | When |
|---|---|
| [Start a project](start-a-project.md) | you want a repository for a new experiment, spike or proof of concept |
| [Report a finding](report-a-finding.md) | an experiment produced a result, positive or negative |
| [Progress updates and demos](progress-and-demos.md) | regularly, while a project is active |

Methodology changes to a benchmark go through that benchmark's public RFC process, for example [inference-proofs/rfcs](https://github.com/ai-verification-observatory/inference-proofs/blob/main/rfcs/README.md).
